App shell and global behavior
Material 3 UI with a purple seed theme, custom light/dark scaffold and app bar styling (lib/app.dart).
Dark / light mode toggle on the home dashboard; preference persisted in SharedPreferences (dark).
Portrait-only orientation in main.dart.
Timezone initialized to Africa/Cairo for scheduling (used with notifications and background work).
Bloc global state (AppBloc) loading subjects, tasks, absences, marks, semesters, timetable, reminders, study topics, subject notes, Jarvis documents, subject metadata (lib/bloc/app_state.dart).
JarvisNavigator: global navigatorKey and shell key for navigation from services/overlays (lib/app.dart, lib/services/jarvis_navigator.dart).

NOVA scheduling and intelligence (cross-cutting)
DailySchedulePage: 7-day weekly grid (30-minute slots from 6 AM), labels (Sleep, Class, Gym, Commute, Family, Mosque, Free, Work, Other), multi-slot paint by dragging, long-press clear, persist to prefs, then NovaSmartScheduleService.generateSmartPlan (loads DB: subjects, tasks, timetable, marks, topics, exam_mistake notes) and fills nova_study_plan.
NovaIntelligenceEngine (WorkManager nova_friday_regen): Friday regeneration of study plan / weekly briefing data in DB; generateWeeklyBriefing for text stored in nova_weekly_briefing.

Jarvis stack (summary)
JarvisOverlay: multi-room chat persisted in jarvis_chat_rooms, markdown + LaTeX, voice pipeline (Groq + optional ElevenLabs), document-aware replies via JarvisBrainService, JarvisService, navigation to shell indices.
JarvisBrainService: Gemini-powered exam prep, knowledge x-ray, night before, full subject analysis, API key management.
JarvisQuizPage: in-overlay quizzes from generated data.
Notifications and background jobs
NotifService: timetable class reminders, task due reminders, Read My Day, urgent task nags, missed notification replay on resume, Android channels, exact-alarm handling, rich actions.
NotifDiag / NotifHealthMonitor: logging to file, layered health checks (permissions, timezone, quota, etc.).
NotifDiagnosticPage: run diagnostics, optional test notification, copy/clear log.
ClassAlarmService: foreground task heartbeat (~1 min) to fire class start notifications reliably and cancel duplicate OS alarms.
MidnightScheduler: daily WorkManager task to recompute odd/even week and reschedule timetable notifications from DB.
main.dart: single Workmanager dispatcher for watchdog, Friday NOVA regen, midnight reschedule.
Data model and persistence (SQLite eng_org_v5.db)
Core tables include subjects, tasks, marks, semesters, timetable, reminders, absences, topics, subject_notes, jarvis_documents, subject_metadata, jarvis_chat_rooms, pomodoro sessions, and NOVA tables nova_study_plan, nova_weekly_briefing, nova_subject_intel, nova_watchdog_apps, etc. (see database.dart).
